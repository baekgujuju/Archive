# 카페 원문 복원과 분리한 기능 검토

2026-10-15. 사용자 요청에 따라 기존 네이버 카페 본문/댓글 원문 재수집, PDF 복원 반영, 북마크릿 교체와 폰 테스트는 마지막 논의로 보류합니다. 해당 자료를 이번 기능 수정 배포에 섞지 않습니다. 전체 운영자료 인계는 최종 사용자 확인 이후입니다.

## 새 수정
- HTML 정제가 표 colspan/rowspan 및 순서 목록 start/value를 안전한 숫자 범위에서 유지합니다.
- 이미지 width/height를 보존하여 지연 로딩 이미지가 높이 0으로 접히지 않도록 합니다.
- 원문 보기 중복 제거와 관련 글 URL 중복 제거를 적용합니다. 원래 글 ID/메모 ID는 유지합니다.
- 작성일로 잘못 수집된 숫자/조회수는 표시하지 않습니다. 날짜 앞 UI 문구를 제거하고 작성일/수집일을 구분합니다.
- 읽기 창 인쇄도 인라인과 같은 별도 출력 영역을 사용하고 모든 이미지를 기다립니다. 이미지 실패 시 출력하지 않고 이유를 표시합니다.
- 번역의 HTML 문단 경계를 유지하고 한국어/외국어 문단 혼합 글의 외국어 문단을 처리합니다. 빈 번역이나 문단 개수 불일치는 성공이 아닙니다. 캐시 검증도 이 조건을 적용합니다.
- HTML 번역은 실제 원문 블록과 정확히 일치하는 문단에만 표시합니다. 일치하지 않는 캐시는 원문을 유지하고 번역 재검토 안내를 표시합니다.

## 확인
- 기존 render/bootstrap/classic script 통합/Drive 병합 및 생명주기/인쇄/관련 글/AI 도구 검사 통과.
- 새 HTML 문단 추출 Python 검사 3개 통과. 실제 DOM에서 표 병합/목록 번호/이미지 크기와 위험 이벤트 제거 검사 통과.
- Chrome에서 320/390/540px 1열, 768/820px 2열, 1024/1440px 3열과 같은 높이 카드, 가로 넘침 없음 확인.
- 실제 필터 주제 차트패턴 선택은 1건으로 줄어들고 전체 보기로 이전 기본 목록이 복구됨.
- PC 인라인 펼침에서 모든 도구가 있으며 카드 밖 제목 클릭으로 접힘.
- 실제 Weekend 글은 한국어 번역 7문단 표시 확인.
- 읽기 제목24px, 이미지 확대창 제목20px, 실제 표 격자 확인.
- 390px 이미지창에서 확대 초기화/원글 보기 보조 버튼이 숨겨지며 가로 넘침 없음.

## Muse 검토 지침
1. 공개 main은 기존 운영 상태를 유지하고 소스 수정만 검토 브랜치에서 비교하세요. 카페 원문 자동 수집/반영은 보류합니다.
2. 변경된 번역 코드로 외국어 글 캐시를 갱신합니다. 이번에는 `python3 v2/translate_posts.py --chunks posts-x.json posts-web.json`으로 카페가 포함된 IB 청크를 제외합니다. 원문 데이터나 기존 정상 번역은 보존합니다. 연속 실패 2회면 종료하며 다음 실행 때 재시도합니다.
3. 브라우저에서 읽기 창과 인라인 각각 인쇄 버튼을 실제 클릭해서 이미지 대기/단일 글 출력/종료 후 화면 복구를 확인하세요. 기존 PDF 검증 근거는 이전 버전의 근거이며 새 수정 검증을 대신하지 않습니다.
4. 실제 iPhone Safari/물리 iPad/폴더블/카카오톡 수신은 아직 검증했다고 보고하지 않습니다. 단순 viewport 검사는 실제 기기 확인과 구분합니다.

## 번역 실행 경로
`ARCHIVE_TRANSLATOR=auto`는 기존 로그인된 Codex CLI가 설치돼 있으면 이를 사용합니다. Muse의 최신 설치 경로 `~/workspace/.npm-global/bin/codex`를 우선하며 `ARCHIVE_CODEX_BIN`으로 지정할 수 있습니다. 모델 기본값은 사용자가 기존에 확인한 `gpt-6.1-sol`이며 `ARCHIVE_TRANSLATION_MODEL`로 설정합니다. 개인 Muse 실행 호스트의 기존 인증을 재사용하고 인증 파일을 복사하거나 GitHub Actions로 옮기지 않습니다. stdin으로 원문을 보내고 읽기 전용·일회 실행의 결과 파일만 읽습니다. 한 호출 제한120초. CLI가 없으면 기존 Gemini 설정을 사용하며 명시적인 `ARCHIVE_TRANSLATOR=gemini`도 지원합니다.

공식 CLI 근거: https://learn.chatgpt.com/docs/non-interactive-mode
