# v2.5.7 — 2026-10-16

## 변경
- 필터 하단 우측 ‘필터 닫기’. 기존 초기화 링크와 같은 색/가벼운 형태. 선택 조건은 유지하고 패널만 닫으며 포커스를 summary로 복귀.
- VOL.002와 앱 버전은 제목 옆 작은 회색 글씨. 우상단은 ‘최신 업데이트 YYYY.MM.DD HH:mm’. KST로 표시하고 content_updated_at 우선, 기존 manifest.version을 대체 근거로 사용. 오프라인은 저장본 표시. 표시만으로 실제 원문 업로드 시각을 더 정밀하게 알 수 없으며 자료가 아카이브 빌드에 반영된 시각임.
- release.json의 앱 버전을 빌더가 읽어 자동 자료 빌드의 2.2.0 하드코딩 회귀 방지. 같은 source_hash로 재빌드하면 기존 content_updated_at 유지. 코드만 배포할 때 manifest.version을 현재 시각으로 바꾸지 않음.
- Drive는 메모리만 사용하던 인증을 현재 탭/설치 앱 세션의 sessionStorage에도 최대 1시간·실제 토큰 만료 이내 저장. 새로고침으로 연결이 무조건 끊기던 문제 개선. localStorage·백업·원문·로그에는 인증을 넣지 않음. 브라우저/앱 종료 뒤 재연결이나 만료 뒤 재인증은 여전히 필요할 수 있음. 과거 메모리 전용 설명보다 이 문서가 우선.
- 연결 시/복귀 시/5초 주기로 읽기만 확인. ‘지금 불러오기’와 헤더 연결/불러오기 진입점 추가. 내려받기/상대 기기 내보내기 시각과 북마크·고정 수 표시. 충돌은 로컬 보존 및 사본 기록, 다른 Drive 파일 기준을 가져와 병합하지 않음.
- 내보내기는 매번 PIN. 쓰기 뒤 원격을 다시 읽어 같아야 성공 표시. 연결/새로고침/포커스/타이머는 쓰기0. 실패 시 로컬 보존.

## 검증
test_sync_reload: 연결→폰 상태 읽기→새 VM 새로고침→더 최신 폰 상태 반영, 초점 복귀, 승인된 1회 쓰기 및 재읽기, 서버 상태 불일치 성공 차단, 만료 복구와 토큰 비노출.
test_updated_label: KST, 자료 시각 우선, 저장본, 잘못된 날짜. test_build_data: 앱 버전/동일 자료 시각 보존 및 변경 시각 갱신.
기존 render/bootstrap/classic/Drive merge·lifecycle/인쇄/관련 글 검사 유지. 실제 PC·모바일 viewport에서 필터 닫기/헤더/가로 넘침 검증.

사용자의 실제 설치형 PC 앱/폰 간 현상은 일반 Chrome 탭 상태로 단정하지 않음. 이번 첫 적용은 구버전에 남은 메모리 인증을 복원할 수 없으므로 한 번 Drive 연결이 필요할 수 있음. 물리 Safari/PWA 수신은 별도 확인해야 함. 새로고침 전 연결됐다는 사실과 새로고침 후 인증 유지 여부는 다름.

## 배포
코드만 경로별 적용. 새 release.json 포함. 원격 최신 manifest의 app_version만 2.5.7, content_updated_at 없으면 기존 version을 복사. 기존 원문 chunks/media/번역/개인 상태를 로컬 QA 데이터로 덮어쓰지 않음. index CSS/JS 쿼리는 모두 2.5.7. 워커/다른 작업과 동시에 정본을 수정하지 않음. review/v2-2.5.5 전체 병합 금지.
인수 원본 codex 폴더는 수정하지 않음. 이후 수정본/배포 근거는 김실장/버전별 폴더에 보관. 카페 과거 자료 복원과 북마크릿 교체는 계속 보류.
