# v2 수동 브라우저 테스트 체크리스트

> node:vm 테스트는 실제 브라우저 테스트가 아님.
> 아래 항목을 데스크톱 Chrome과 iOS Safari에서 직접 확인해야 함.

## 테스트 URL
- 로컬: http://localhost:8899/index.html (로컬 서버 실행 시)
- 리뷰 브랜치: https://github.com/baekgujuju/Archive/tree/review/v2-complete
- 프로덕션 (main push 후): https://baekgujuju.github.io/Archive/v2/

## 1. 기본 로딩 (데스크톱 + 모바일)
- [ ] 페이지 열기 → "아카이브를 불러오는 중..." 스피너 표시
- [ ] 스피너가 사라지고 카드 목록 표시 (무한 로딩 없어야 함)
- [ ] 헤더에 카드 개수 표시 (159 + Oliver Kell 1 = 160 예상)
- [ ] 브라우저 콘솔에 오류 없음 (F12 → Console)

## 2. 카드 렌더링
- [ ] 각 카드에 제목/저자/날짜/요약 표시
- [ ] 이미지가 있는 카드에 썸네일 표시
- [ ] 이미지 클릭 → 라이트박스로 확대 표시
- [ ] 답글이 있는 카드에 "💬 댓글 N개" 표시
- [ ] 답글 펼치기 → 답글 목록 표시

## 3. 검색/필터
- [ ] 검색창에 키워드 입력 → 실시간 필터링
- [ ] OR/AND 토글 동작
- [ ] 유형 탭 (X/웹글) 필터 동작
- [ ] 주제/저자 칩 필터 동작

## 4. 메모
- [ ] 메모 버튼 클릭 → 편집 모달 표시
- [ ] 메모 저장 → 새로고침 후 유지됨
- [ ] 메모 있는 카드에 표시 (아이콘 강조)

## 5. 북마크
- [ ] 북마크 버튼 클릭 → 7색 선택 UI (빨강/주황/노랑/초록/파랑/남색/보라)
- [ ] 색상 선택 → 카드 왼쪽 테두리에 색상 표시
- [ ] v1에서 저장한 기존 북마크(hex)가 그대로 표시됨
- [ ] 북마크 필터로 색상별 필터링

## 6. 핀/숨기기
- [ ] 핀 버튼 → 최상단 고정 섹션에 표시
- [ ] 삭제 버튼 → 확인 후 숨김
- [ ] 설정에서 숨긴 글 복원

## 7. 읽기 모달
- [ ] 카드 클릭 → 전체화면 읽기 모달
- [ ] 본문 전체, 이미지, 답글, URL 내용 표시
- [ ] ESC/닫기 버튼으로 닫기

## 8. 공유
- [ ] 🖼️ 이미지로 공유 → PNG 생성 (또는 다운로드)
- [ ] 🌐 HTML로 공유 → 독립 HTML 파일 (텍스트+출처 포함)
- [ ] 🖨️ 인쇄 → 인쇄 미리보기

## 9. Drive 동기화
- [ ] 설정에서 "🔗 Drive 연결" 버튼 표시
- [ ] 클릭 → Google OAuth 팝업
- [ ] 연결 후 상태 표시 "☁️ Drive 연결됨"

## 10. 반응형
- [ ] 모바일 (390px): 1열, 44px 터치 타겟
- [ ] 태블릿 (768px): 2열
- [ ] 데스크톱 (1024px+): 3열

## 콘솔 오류 체크
데스크톱 Chrome에서 F12 → Console 탭:
- [ ] 빨간색 오류 없음
- [ ] 노란색 경고 확인 (무시 가능한 것만 있는지)

## iOS Safari 특별 체크
- [ ] safe-area (노치 영역) 대응
- [ ] 100dvh 사용으로 주소창 가림 문제 없음
- [ ] 터치 스크롤 부드러움
- [ ] Web Share API 동작 (공유 시트)
